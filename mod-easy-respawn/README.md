# Модуль для AzerothCore Easy respawn

## Обзор

Добавляет возможность воскрешения и телепортации игроков к началу подземелий или рейдов вместо ближайшего кладбища. Настройки также позволяют игрокам мгновенно возрождаться в открытом мире. Этот модуль также работает с ботами-игроками (playerbots), влияя на то, как они воскрешаются.


## Как установить

1. Клонируйте этот репозиторий в папку `modules` вашего репозитория AzerothCore. Теперь там должна появиться папка `mod-easy-respawn`.
2. Запустите CMake повторно, чтобы сгенерировать решение (solution).
3. Пересоберите проект.
4. После сборки файл `mod_easy_respawn.conf.dist` должен появиться в директории `configs/modules`; скопируйте его в папку `configs/modules` в корневом каталоге сервера (удалив при этом расширение `.dist`).
5. Запустите сервер и наслаждайтесь игрой.

## Как использовать

Откройте файл **mod_easy_respawn.conf** и проверьте параметр **EasyRespawn.Active**.

Вы можете легко отключить определенные карты с помощью параметра **EasyRespawn.DisabledMapIds**: просто перечислите ID карт через запятую.

Если вы хотите изменить точку возрождения для конкретных карт, достаточно добавить соответствующую строку в файл конфигурации: **EasyRespawn.OverrideRespawnLocation.YOUR_MAP_ID=new_map_id,new_pos_x,new_pos_y,new_pos_z,new_orientation**. Пример такой настройки для Цитадели Ледяной Короны (ID карты 631) уже присутствует в файле.
