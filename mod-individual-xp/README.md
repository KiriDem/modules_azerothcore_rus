## Модуль Individual XP

Этот модуль позволяет каждому игроку просматривать, включать, отключать и изменять свой множитель опыта, не затрагивая при этом настройки других игроков. Доступ к этим функциям возможен в любой момент с помощью команд. Именно игрок сам решает, как играть (в «медленном» или «быстром» темпе), а не сервер навязывает ему этот выбор.

# Как установить

1. Скопируйте этот модуль в каталог `modules` основного исходного кода.
2. Запустите CMake.
3. Выполните компиляцию.

# Настройки

В файле конфигурации необходимо настроить два параметра:

- `IndividualXp.Enabled`
- Включение или отключение модуля IndividualXP.
- `IndividualXp.Announce`
- Оповещение о работе модуля IndividualXP при входе в игру.
- `IndividualXp.AnnounceRatesOnLogin`
- При входе в игру игроку отображаются текущие и максимальные значения множителя опыта.
- `IndividualXp.MaxXPRate`
- Максимальное значение множителя опыта, которое может установить игрок.
- `IndividualXp.DefaultXPRate`
- Значение множителя опыта по умолчанию, с которым начинают игру игроки.

Переменная `Max XP Rate` определяет максимально допустимый для игрока множитель получения опыта. В то же время переменная `Default XP Rate` задает начальный множитель, а также тот, который будет установлен при использовании команды `.xp default`. Рекомендуется установить одинаковые значения для множителей опыта по умолчанию и максимального множителя. В этом случае все игроки изначально будут получать опыт с максимальной для сервера скоростью, но при желании смогут изменить этот параметр с помощью команды `.xp set`.

# Комманды игрока

| Комманда     | Описание                                       |
|-------------|---------------------------------------------------|
| .XP         | Команда основного модуля                               |
| .XP View    | Отображает текущий коэффициент получения опыта                      |
| .XP Set #   | Изменяет множитель опыта на указанное значение.        |
| .XP Default | Возвращает множитель опыта к стандартному значению.          |
| .XP Disable | Отключает получение опыта до тех пор, пока пользователь не введет команду '.XP Enable' |
| .XP Enable  | Включает получение опыта, если оно было отключено.           |
