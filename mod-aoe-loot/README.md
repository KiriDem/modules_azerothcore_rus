# mod-aoe-loot

[Russian](README.md) | [English](README_EN.md)

## Описание

Этот модуль включает функцию обыска трупов в зоне действия (AOE) для AzerothCore, позволяя игрокам грабить несколько ближайших трупов, взаимодействуя только с одним из них. Все предметы и золото с трупов в пределах настроенного диапазона автоматически собираются в едином окне добычи.

## Особенности

- **AOE мародерство**: Автоматически собирайте добычу из нескольких близлежащих трупов с одним взаимодействием
- **Команды переключения для игроков**: Individual players can enable/disable AOE loot using `.aoeloot on/off` commands
- **Поддержка нескольких языков**: Full internationalization support with English and Spanish translations (easily extensible to other languages)
- **Настраиваемый диапазон**: Server administrators can set the maximum distance for AOE loot collection
- **Поддержка групп**: Optional group looting with configurable settings
- **Оптимизирована производительность**: Limits number of corpses processed to maintain server stability
- **Интеллектуальное управление предметами**:
  - Автоматическое накопление золота с защитой от переполнения
  - Квестовые предметы отправляются непосредственно в инвентарь
  - Максимум 15 предметов на окно лута для предотвращения проблем с пользовательским интерфейсом
- **Управление трупами**: Автоматически очищает разграбленные трупы, чтобы уменьшить беспорядок

## Установка

### 1. Клонирование модуля

**Внимание:** это действие скопирует в каталог все модули из этого репозитория
Перейдите в каталог модулей AzerothCore:
```bash
cd <ACoreDir>/modules
git clone https://github.com/KiriDem/modules_azerothcore_rus.git
```

### 2. Компиляция

Повторно скомпилируйте AzerothCore:

```bash
cd <ACoreDir>/build
cmake ../ -DCMAKE_INSTALL_PREFIX=/path/to/server -DCMAKE_C_COMPILER=/usr/bin/clang -DCMAKE_CXX_COMPILER=/usr/bin/clang++
make -j $(nproc)
make install
```

### 3. Настройка

Отредактируйте свой `worldserver.conf` или `mod_aoe_loot.conf` в папке конфигураций:

```conf
########################################
# НАСТРОЙКИ МОДУЛЯ AOE LOOT
########################################
#
#    AOELoot.Enable
#        Описание: Включение модуля
#        По умолчанию:     1 - (Включенно)
#                          0 - (Выключенно)
#

AOELoot.Enable = 1

#
#    AOELoot.Message
#        Описание: Показывать информационное сообщение при входе игрока в систему.
#        По умолчанию:     1 - (Включенно)
#                          0 - (Выключенно)
#

AOELoot.Message = 1

#
#    AOELoot.Range
#       Описание: Поиск добычи с максимальным радиусом действия.
#       По умолчанию:    55.0
#       Радиус:          5.0 - 100.0
#

AOELoot.Range = 55.0

#
#    AOELoot.Group
#        Описание: Включает сбор добычи, если игрок находится в группе.
#        По умолчанию:     1 - (Включенно)
#                          0 - (Выключенно)
#

AOELoot.Group = 1

###################################################################################################
```

### 4. Конфигурация разложения трупа (ВАЖНО)

Для оптимального опыта, измените настройки распада трупа в `worldserver.conf`:

```conf
#
#    Rate.Corpse.Decay.Looted
#        Description: Multiplier for Corpse.Decay.* to configure how long creature corpses stay
#                     after they have been looted.
#        Default:     0.5
#        Recommended: 0.01 (for AOE Loot module)

Rate.Corpse.Decay.Looted = 0.01
```

**Почему это важно:** Скорость разложения по умолчанию (0,5) может привести к задержке трупов после разграбления с помощью AOE, создавая визуальный беспорядок. Установка этого значения на 0.01 гарантирует быстрое исчезновение трупов после разграбления.

### 5. Перезапуск сервера

Перезагрузите свой Worldserver, чтобы загрузить модуль:

```bash
./worldserver
```

## Использование

### Для Игроков

#### Команды
- `.aoeloot on` - Включите AOE looting для вашего персонажа
- `.aoeloot off` - Отключите AOE looting для вашего персонажа

#### Как использовать
1. Убейте нескольких врагов в непосредственной близости
2. Щелкните правой кнопкой мыши на любом трупе, чтобы разграбить его
3. Все предметы с ближайших трупов появятся в одном окне добычи
4. Квестовые предметы автоматически добавляются в ваш инвентарь
**Примечание:** Настройки игрока сбрасываются при выходе из системы. Добыча AOE включена по умолчанию, если модуль активен.

### Для администраторов

Модулем можно управлять с помощью настроек файла конфигурации (см. Раздел Конфигурации выше).

## Параметры конфигурации

| Параметр | Тип  | По умолчанию | Описание    |
|----------|------|--------------|-------------|
| `AOELoot.Enable` | Boolean | 1 | Включать / отключать модуль глобально |
| `AOELoot.Range` | Float | 55.0 | Максимальный радиус сбора добычи (5.0 - 100.0) |
| `AOELoot.Group` | Boolean | 1 | Разрешить добычу AOE в группах |
| `AOELoot.Message` | Boolean | 1 | Показать сообщение о входе в систему |

## Поддержка нескольких языко

Модуль включает в себя полную поддержку нескольких языков через систему AzerothCore `module_string_locale`.

### Поддерживаемые В настоящее Время языки
- Английский (en_US)
- Испанский (es_ES / es_MX)
- Русский (ru_RU)

### Добавление дополнительных языков

Чтобы добавить дополнительную языковую поддержку, обновите файл SQL `aoe_loot_module_string.sql`.

## Технические детали

### Записи в базе данных

Модуль использует записи `module_string_locale` 50000-50007:

| Вход | Постоянная | Цель |
|-------|----------|---------|
| 50000 | AOE_ACORE_STRING_MESSAGE | Сообщение для входа в систему |
| 50001 | AOE_ITEM_IN_THE_MAIL | Уведомление по почте (зарезервировано) |
| 50002-50003 | - | Зарезервировано для использования в будущем |
| 50004 | AOE_LOOT_ALREADY_ENABLED | Сообщение "Уже включено" |
| 50005 | AOE_LOOT_ENABLED | Подтверждение "Включено" |
| 50006 | AOE_LOOT_ALREADY_DISABLED | Сообщение "Уже отключено" |
| 50007 | AOE_LOOT_DISABLED | Подтверждение "Отключено" |

### Соображения в отношении производительности

- Максимум 10 трупов, обрабатываемых за одну операцию добычи (жестко запрограммировано для стабильности)
- Максимум 15 предметов в окне добычи
- Защита от переполнения золотом (предотвращает превышение максимального значения uint32)
- Эффективная фильтрация и очистка трупов

## Устранение неполадок

### Проблема: AOE loot не работает

**Решение:**
- Убедитесь, что модуль включен: `AOELoot.Enable = 1`
- Проверьте, отключили ли вы его лично: используйте `.aoeloot on`
- Убедитесь, что вы находитесь в пределах досягаемости (по умолчанию 55 ярдов)
- Если вы находитесь в группе, проверьте настройку `AOELoot.Group`

### Проблема: Трупы не исчезают

**Решение:**
- Установить `Rate.Corpse.Decay.Looted = 0.01` в worldserver.conf

### Проблема: Сообщения на неправильном язык

**Решение:**
- Убедитесь, что SQL был импортирован правильно
- Проверьте настройки языкового стандарта клиента
- Подтвердите, что в таблице `module_string_locale` есть перевод для вашего региона

### Проблема: "Уже включено / отключено" отображаются некорректно

**Решение:**
- Это ожидаемое поведение - настройки сбрасываются при выходе из системы
- При первом входе в систему AOE-добыча включена по умолчанию

## Известные ограничения

- Настройки игрока не сохраняются во время сеансов выхода из системы
- Одновременно обрабатывается не более 10 трупов (ограничение производительности)
- Квестовые предметы, отправленные в инвентарь могут быстро наполнить сумки
- Диапазон ограничен максимум 100 ярдами
