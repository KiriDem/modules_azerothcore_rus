# <img width="100" height="100" alt="icon" src="https://github.com/user-attachments/assets/093a515e-ac44-4e0a-812d-2e3d1847c71f" /> mod-auto-gather

Модуль для AzerothCore, который автоматически собирает ресурсы (руду и травы) и снимает шкуры с существ, когда игроки проходят рядом с ними. Добыча сразу попадает в сумки — без полос применения, окон с лутом и лишних кликов.

## Особенности

- **Автоматический сбор ресурсов с точек сбора** — Жилы и места сбора трав в радиусе действия собираются автоматически. Объект исчезает и восстанавливается в обычном режиме.
- **Автоматическое снятия шкур** — Мертвые существа, с которых уже собрана вся добыча и которые помечены как пригодные для снятия шкуры, разделываются автоматически. Это также работает с существами, для разделки которых требуются навыки травничества или горного дела.
- **Отслеживание на мини-карте** — У игроков с соответствующим навыком на мини-карте автоматически включено отслеживание трав и минералов. Оба режима могут работать одновременно (это обходит стандартное ограничение, позволяющее использовать лишь одно заклинание отслеживания).
- **Развитие навыков** — Повышение навыка сбора ресурсов происходит в обычном режиме, по тем же формулам, что и в базовой игре. За снятие шкур с элитных существ навык повышается активнее.
- **Безопасность заполнения сумок** — перед сбором ресурсов проверяется наличие свободного места в сумках. Если сумки заполнены, ресурсный узел или труп остаются нетронутыми.
- **Предметы для заданий и золото** — Добыча для заданий и золото из точек сбора собираются автоматически.

## Требования

- AzerothCore с актуальным исходным кодом

## Installation

1. Клонируйте в ваш каталог `modules/`:
   ```bash
   git clone https://github.com/KiriDem/modules_azerothcore_rus.git
   ```
2. Запустите CMake повторно и пересоберите сервер.
3. Скопируйте `conf/mod_auto_gather.conf.dist` в каталог конфигурации вашего сервера под именем `mod_auto_gather.conf`.

## Настройка

Все параметры находятся в файле `mod_auto_gather.conf`:

| Параметр | По умолчанию | Описание |
|---|---|---|
| `AutoGather.Enable` | `1` | Полностью включить/отключить модуль |
| `AutoGather.Announce` | `1` | Показывать сообщение в чате при входе в систему|
| `AutoGather.AutoTrack` | `1` | Автоматически включать отслеживание на мини-карте для собирательных профессий |
| `AutoGather.AutoLoot` | `1` | Автоматический сбор ресурсов и снятие шкур с существ |
| `AutoGather.LootRange` | `10.0` | Дистанция (в ярдах) для срабатывания автосбора |
| `AutoGather.ScanIntervalMs` | `1000` | Миллисекунды между сканированиями для каждого игрока |
| `AutoGather.AllowInCombat` | `0` | Разрешить сбор ресурсов во время боя |
| `AutoGather.AllowWhileMounted` | `1` | Разрешить сбор ресурсов при езде на маунте |

Все настройки поддерживают «горячую» перезагрузку. (`.reload config`).

## Как это работает

Каждый игрок сканируется по настраиваемому таймеру. При каждом сканировании модуль:

1. Проверяет состояние игрока (жив, не в полете, не в транспорте, не применяет заклинание, не находится под действием эффектов контроля).
2. Устанавливает флаги отслеживания на мини-карте, если у игрока есть навык «Травничество» или «Горное дело».
3. Ищет поблизости игровые объекты (ресурсы), соответствующие уровню навыка игрока.
4. Ищет поблизости трупы существ, пригодные для снятия шкур в соответствии с уровнем навыка игрока.
5. Собирает один ресурс **или** снимает шкуру с одного существа за цикл, чтобы процесс выглядел естественно.

Игроки должны иметь изученную соответствующую профессию по сбору ресурсов — модуль учитывает требования к навыкам точно так же, как и базовая игра.
