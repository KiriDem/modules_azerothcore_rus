# Junk to Gold Plus

> Это форк оригинального мода [mod-junk-to-gold](https://github.com/noisiver/mod-junk-to-gold.git) модуля для [AzerothCore](https://github.com/azerothcore/azerothcore-wotlk.git).

Как и оригинал, этот модуль автоматически продает предметы серого качества (низкого качества) сразу после их получения.

В этой версии добавлены механизмы защиты, предотвращающие автоматическую продажу серых предметов, которые могут оказаться полезными.

Исключения (предметы, которые не будут продаваться автоматически):

- Предметы для заданий (включая предметы, начинающие задание).
- Серая броня и оружие, которые могут служить улучшением для текущей экипировки игрока.
- Серое снаряжение, необходимое для выполнения текущей цели задания.

## Установка

Этот модуль предназначен для AzerothCore.

### Предварительные требования

- Настроенная среда с исходным кодом AzerothCore.
- Установленный Git.
- Успешная базовая сборка AzerothCore (выполненная до добавления этого модуля).

### 1. Перейдите в директорию модулей AzerothCore

Из корневой директории AzerothCore:

```bash
cd modules
```

### 2. Клонируйте этот модуль

```bash
git clone https://github.com/TrisBits/mod-junk-to-gold-plus.git
```

This will create:

```text
azerothcore/
  modules/
    mod-junk-to-gold-plus/
```

### 3. Сборка AzerothCore

Запустите это из корневого каталога AzerothCore (каталога, содержащего `acore.sh`):

```bash
./acore.sh compiler all
```

Для последующих небольших обновлений обычно можно использовать более быструю команду, выполняющую только сборку:

```bash
./acore.sh compiler build
```

### 4. Скопируйте и отредактируйте конфигурацию модуля

В комплект поставки модуля входит файл:

- `conf/mod_junk_to_gold_plus.conf.dist`

Скопируйте его в директорию конфигурации вашего сервера и удалите расширение `.dist` из имени скопированного файла.

Стандартная директория конфигурации для сборок AzerothCore из исходного кода:

- `env/dist/etc`

Типичный пример для Linux:

```bash
cp ../modules/mod-junk-to-gold-plus/conf/mod_junk_to_gold_plus.conf.dist ../env/dist/etc/mod_junk_to_gold_plus.conf
```

Типичный пример для Windows PowerShell:

```powershell
Copy-Item ..\modules\mod-junk-to-gold-plus\conf\mod_junk_to_gold_plus.conf.dist ..\env\dist\etc\mod_junk_to_gold_plus.conf
```

Откройте скопированный файл и настройте параметры по своему усмотрению.

### 5. Перезапуск worldserver

Перезапустите worldserver, чтобы модуль и конфигурация загрузились.

### 6. Проверка работоспособности

Войдите в игру персонажем, подберите предмет «серого» качества (хлам) и убедитесь, что:

- Предмет продается автоматически.
- Деньги начисляются корректно.
- Сообщение о продаже в чате появляется только при `JunkToGoldPlus.Enable = 1` и `JunkToGoldPlus.EnableSaleChat = 1`.

### Примечания

- Не запускайте одновременно оригинальный `mod-junk-to-gold` и этот форк, если только вы намеренно не хотите дублирования хуков обработки добычи.

## Обновление

Чтобы обновить этот модуль в дальнейшем, выполните следующую команду из корневой директории AzerothCore:

```bash
cd modules/mod-junk-to-gold-plus
git pull
cd ../..
./acore.sh compiler build
```

## Конфигурация

`JunkToGoldPlus.Enable` (по умолчанию: `1`)

- `1`: Включить модуль.
- `0`: Отключить модуль, не удаляя его из папки модулей AzerothCore.

`JunkToGoldPlus.EnableSaleChat` (по умолчанию: `1`)

- `1`: Отправлять сообщения в чат при автоматической продаже «серых» предметов.
- `0`: Отключить сообщения о продаже в чате для более незаметной работы и незначительного снижения нагрузки на систему.
