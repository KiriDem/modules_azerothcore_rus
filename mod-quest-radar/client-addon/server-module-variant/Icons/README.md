# Иконки/

`glow.blp` — круглая текстура с мягким (градиентным) краем; используется
скриптом `Minimap.lua` для отрисовки полупрозрачной «области» цели
(окрашенной в синий цвет с помощью `Texture:SetVertexColor`).

Файл взят «как есть» (бинарный файл `.blp`, без программного кода) из
репозитория [Questie-335](https://github.com/divial28/Questie-335)
(`Icons/glow.blp`) — форка Questie, специально нацеленного на
совместимость с оригинальным клиентом WotLK версии 3.3.5.12340 (тем же,
для которого предназначен и данный модуль). Questie распространяется
по лицензии GPL-3.0; если вы планируете публичное распространение
этого модуля, убедитесь, что такое использование соответствует условиям
лицензии (информация об авторстве сохранена в данном файле).

## Почему изображение, а не сплошной цвет

В предыдущей версии область заливалась простым сплошным цветом
(`Texture:SetTexture(r,g,b,a)` без указания файла). Проблема, выявленная в игре:
в WoW версии 3.3.5 нет встроенной функции обрезки текстур аддонов по кругу —
квадрат достаточного размера всегда будет выходить за границы круглой
мини-карты, независимо от его габаритов (это обусловлено геометрией, а не настройками).
Использование готового круглого изображения с мягкими краями позволяет
избежать этой проблемы.
