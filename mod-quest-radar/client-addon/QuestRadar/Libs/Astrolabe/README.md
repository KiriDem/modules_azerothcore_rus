# Astrolabe (библиотека)

Размещает значки на мини-карте: преобразует нормализованные координаты карты в смещение на мини-карте, учитывая масштаб, поворот, форму мини-карты и ограничение положения значков по её краям.

## Происхождение

Скопировано из репозитория [Trimitor/WDM-addons](https://github.com/Trimitor/WDM-addons)
(`!Astrolabe`) — это форк, предназначенный именно для клиента версии 3.3.5.12340.
Оригинальный автор — Esamynn; над данным форком работали Esamynn и Trimitor.

- Идентификатор библиотеки: `Astrolabe-0.4`, ревизия **107**
- Оригинальная версия `Astrolabe-1.0` **здесь не подходит**: она рассчитана на
Mists of Pandaria (`## Interface: 50001`) и вызывает `GetAreaMaps()` внутри
функции `activate()`, которая выполняется при загрузке. В версии 3.3.5a
такой функции не существует, поэтому библиотека сразу же прекращает работу —
причем без вывода ошибок, так как в этом клиенте параметр `scriptErrors`
по умолчанию равен `0`. Кроме того, она регистрируется под другим основным
именем, поэтому даже не смогла бы заменить собой текущую версию.

## Почему используется встроенная копия, а не внешняя зависимость

Благодаря этому аддон работает сразу после скачивания. DongleStub устраняет дублирование на основе основного имени (major name) и оставляет версию с наибольшим номером минорного обновления (minor version). В результате, если у игрока установлен и отдельный аддон `!Astrolabe`, в памяти останется только один экземпляр (тот, что новее) — конфликтов и дублирования не возникнет. Именно для этого и нужен DongleStub.

В файле `.toc` сохранена строка `## OptionalDeps: !Astrolabe`: её отсутствие ни на что не влияет, а наличие обеспечивает отдельной копии аддона более выгодный порядок загрузки.

## Лицензия

LGPL — см. файл `lgpl.txt`, который, согласно требованиям лицензии, находится рядом с исходным кодом.

## Обновление

Полностью замените четыре файла (Lua/XML) на файлы из указанного выше форка, сохраните `lgpl.txt` и проверьте номер ревизии, указанный здесь. Не заменяйте их на официальный релиз `Astrolabe-1.0`.
