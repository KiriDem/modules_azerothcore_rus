# Quest Radar

Значки целей заданий в стиле Cataclysm на мини-карте для версии **WotLK 3.3.5a**;
предназначено для оригинального клиента 3.3.5.12340 (именно такой использует
AzerothCore — в отличие от современного клиента Blizzard «WotLK Classic»,
у которого другой API).

В WotLK пронумерованные маркеры целей заданий (POI) уже отображаются на
*карте мира* стандартными средствами игры. Однако на мини-карте они не
отображались — этот аддон восполняет данный пробел, используя те же самые
данные и графические элементы.

## Требования

Всего одно: сервер, в базе данных мира которого заполнена таблица `quest_poi`
(в стандартной сборке AzerothCore она заполнена). Если на карте мира также
не отображаются пронумерованные кружки, значит, данные отсутствуют на стороне
сервера.

**Серверный модуль не требуется, как и установка чего-либо еще.** Если на
сервере запущен [`mod-quest-radar`](../../README.md), аддон распознает его
и переключится в режим отображения одного значка на каждую *цель* задания
(вместо одного значка на всё задание) — см. [`../README.md`](../README.md).

Библиотека Astrolabe включена в состав аддона (находится в папке `Libs/Astrolabe/`);
она преобразует координаты карты мира в смещение на мини-карте, учитывая
масштаб, поворот, форму мини-карты и ограничение отображения по краям.
Если у вас также установлен отдельный аддон `!Astrolabe`, библиотека
DongleStub сохранит более новую версию — конфликта не возникнет.
Информацию об источнике и лицензии см. в файле
[`Libs/Astrolabe/README.md`](Libs/Astrolabe/README.md).

## Установка

Скопируйте папку, содержащую файл `QuestRadar.toc`, в директорию
`World of Warcraft\Interface\AddOns\`, затем отметьте **QuestRadar**
в списке аддонов при входе в игру. Не забудьте скопировать и папку `Libs/`.

После первой установки полностью перезапустите клиент игры, а не просто
используйте команду `/reload` — этот клиент считывает новые файлы только
при запуске.

## Настройки

Доступны два равнозначных способа настройки; оба они изменяют одну и ту же
базу данных `QuestRadarDB`:

- **Esc > Интерфейс > Модификации > QuestRadar** — стандартная панель
настроек, не требующая Ace3 или сторонних библиотек. Изменения применяются
сразу после изменения параметров.
- Команды `/qr`, перечисленные ниже. ## Команды

| Команда | Действие |
|---|---|
| `/qr` | Переключить состояние радара |
| `/qr on` / `/qr off` | Явно включить / выключить |
| `/qr status` | Диагностика: наличие библиотеки Astrolabe, текущая карта, задания, обнаруженные точки интереса (POI), размещенные значки |
| `/qr module` | Использовать серверный модуль `mod-quest-radar` при его наличии на сервере (включено по умолчанию) |
| `/qr tracked` | `on` (по умолчанию): только задания, отмеченные в трекере целей. `off`: все задания на карте |
| `/qr completed` | Показать или скрыть значки сдачи (`?`) для выполненных заданий |
| `/qr edge` | Показать или скрыть цели, находящиеся вне зоны видимости (отображаются на краю мини-карты) |
| `/qr scale <0.5-3>` | Размер значков |

Команда `/qr arrows` сохранена как псевдоним для `/qr edge`.

Выбор задания — в журнале заданий или на карте мира — подсвечивает его значки
стандартным для Blizzard свечением выделения. Если задание состоит из нескольких целей,
подсвечиваются все они одновременно.

## Полезная информация

- Статус отслеживания задания — это исключительно клиентская настройка. При включенном
режиме `/qr tracked` (по умолчанию) нумерация привязана к трекеру целей, а не к
карте мира, точно так же, как в стандартном элементе `WatchFrame` от Blizzard;
показания могут различаться, если отслеживание цели отключено. Отключите эту опцию,
чтобы вернуть нумерацию, соответствующую карте мира.
- Зоны поиска задания (так называемые *blobs*) — полупрозрачные области, отображаемые
на карте мира для целей с неточными координатами, — на мини-карте не рисуются. 
Их центр и радиус определяются значениями, которые не возвращает ни одна Lua-функция
клиента; подробнее см. в [`../README.md`](../README.md).

## Файлы

- `QuestRadar.toc` — манифест.
- `QuestRadar.lua` — перечисление точек интереса (POI) и отрисовка на мини-карте.
- `Sync.lua` — опциональная синхронизация с серверным модулем (через `CHAT_MSG_ADDON`).
- `Options.lua` — встроенная панель настроек.
- `Libs/Astrolabe/` — включенная в состав библиотека; см. её собственный файл README.
