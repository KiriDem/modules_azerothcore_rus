# Клиентские аддоны

Здесь представлены две реализации одной и той же идеи. **Одновременно можно установить только одну из них** — обе они используют команду `/qr`, переменную `QuestRadarDB` для сохранения настроек и одни и те же графические элементы (фреймы).

## `QuestRadar/` — рекомендуемый вариант

Считывает данные о точках интереса (POI) квестов, уже имеющиеся в клиенте версии 3.3.5a, и отображает их на мини-карте с помощью встроенной библиотеки [!Astrolabe](https://github.com/Trimitor/WDM-addons).

- **Не требует серверного модуля.** Работает на любом сервере AzerothCore, где в базе данных мира заполнена таблица `quest_poi` (в стандартной сборке она заполнена).
- Один значок на задание; нумерация совпадает с картой мира.
- Если на сервере установлен модуль `mod-quest-radar`, аддон переключается в режим отображения одного значка на *группу целей* (стандартный API клиента выдает только одну точку POI на задание, тогда как модуль не имеет такого ограничения). Команда `/qr module` отключает это улучшение, а `/qr status` показывает, какой источник данных используется в данный момент.

См. файл [README](QuestRadar/README.md).

## `server-module-variant/` — справочный вариант (не входит в комплект)

Оригинальный аддон, получающий координаты не от клиента, а от модуля через канал связи `CHAT_MSG_ADDON`. Сохранен для справки; реализованная в нем функция отображения отдельных целей теперь перенесена в основной аддон. Чтобы использовать этот вариант, переименуйте папку в `QuestRadar/` и приведите имя файла `.toc` в соответствие с названием папки.

## Почему не отображаются зоны поиска

Полупрозрачную область, которую карта мира показывает для неточно определенных целей, невозможно перенести на мини-карту силами одного лишь клиента: в версии 3.3.5a нет Lua-функции, возвращающей геометрию такой области; функция `DrawQuestBlob` рисует изображение за пределами своего фрейма, а в клиенте отсутствует метод `SetClipsChildren` для обрезки изображения. Для отрисовки зоны необходимы координаты центра и радиус в числовом виде — эти данные предоставляет только серверный модуль (`areaX`/`areaY`).
