## mod-ah-bot Расширенный калькулятор цен
Эта электронная таблица помогает отобразить цены покупки и продажи, которые бот(ы) будут использовать в зависимости от вашей конфигурации.`AuctionHouseBot.AdvancedPricing.<Category>.<Subclass>.Enabled` если `true` .  

### Способ применения
**Редактируйте только вкладку «Config».**
   - На этой вкладке представлено множество настраиваемых параметров из файла конфигурации модуля.
   - Измените эти значения в соответствии с настройками вашего сервера.
   - Элементы на других вкладках ссылаются на вкладку `Config`, поэтому значения будут обновляться мгновенно.

<br>

**Вам не должно потребоваться вносить изменения за пределами листа Config, если только вы точно не знаете, что делаете.**  
*На каждой вкладке есть скрытые столбцы, в которых можно отобразить качество, цену у торговца и уровень предмета (согласно данным базы).  
Если вы вносите в данные базы изменения по индивидуальному заказу, не забудьте также обновить их для обеспечения точности цен.*

### Примечания
- Электронная таблица не учитывает следующие настройки:  
    - AuctionHouseBot.Buyer.AcceptablePriceModifier  
    - AuctionHouseBot.BidVariationHighReducePercent  
    - AuctionHouseBot.BidVariationLowReducePercent  
    - AuctionHouseBot.BuyoutBelowVendorVariationAddPercentEnabled  
    - AuctionHouseBot.BuyoutBelowVendorVariationAddPercent
