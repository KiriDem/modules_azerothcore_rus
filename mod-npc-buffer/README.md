### Описание

Этот NPC накладывает на игрока определенный набор усиливающих заклинаний (баффов) по одному щелчку мыши. Он может накладывать одинаковые эффекты на всех или подбирать их в зависимости от уровня игрока. После каждого использования NPC произносит случайную фразу (настраиваемую) и может привлекать внимание игрока с помощью настраиваемых эмоций.

- Создание NPC для наложения баффов с использованием эмоций
- Наложение баффов без необходимости вести диалог
- Возможность наложения одинаковых баффов или подбора эффектов по уровню игрока
- Отправка игроку случайных сообщений (шепотом) после каждого использования
- Привлечение внимания игрока с помощью настраиваемых эмоций
- Настройки:
- Наложение баффов в зависимости от уровня
- ID заклинаний для баффов
- Включение/отключение снятия эффекта «Болезнь воскрешения»
- Настройки эмоций
