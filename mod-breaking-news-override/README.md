# Breaking News Override

<img width="1540" height="1028" alt="image" src="https://github.com/user-attachments/assets/763cb64f-7f44-4843-b05c-71daf0bcf669" />

Этот модуль использует Warden Payload Manager для активации фрейма «Срочные новости» (Breaking News) в левой части экрана выбора персонажа.

Для использования нужно передать ему HTML-файл, указанный в конфигурации.

# Настройка

- Создайте HTML-файл, содержащий тело для фрейма с новостями.
- Укажите путь к HTML-файлу в конфигурации.
- Включите модуль и войдите в систему, чтобы убедиться, что он работает.

# Как создать файл

```html
<html>
<body>
    <p>|cffFF6F51 Команда и владельцы AzerothCore ни при каких обстоятельствах не спонсируют и не поддерживают незаконные публичные серверы. Если вы используете эти проекты для запуска незаконного публичного сервера, а не для тестирования и обучения, — это ваш личный выбор.|r</p>
    <br/>
    <p>У нас есть активное сообщество разработчиков, участников и пользователей, которые сотрудничают, обмениваются знаниями и оказывают поддержку на форумах, в каналах Discord и на других коммуникационных платформах. Если вы хотите внести свой вклад, мы будем этому очень рады!</p>
    <br/>
    <p>Система отличается высокой модульностью, что позволяет разработчикам расширять и настраивать игру в соответствии со своими предпочтениями или создавать уникальный игровой опыт. Такая гибкость дает возможность добавлять пользовательские функции, контент и модификации.</p>
</body>
</html>
```

- `BreakingNews.Enable = 1`
- `BreakingNews.Title = "AzerothCore"`
- `BreakingNews.HtmlPath = "./breakingnews.html"`
- `BreakingNews.Cache = 1`
- `BreakingNews.Verbose = 0`

# Примечания

- Существует небольшое количество HTML-тегов, которые действительно поддерживаются; следуйте этому руководству: https://wowwiki-archive.fandom.com/wiki/UIOBJECT_SimpleHTML
- В заголовке и HTML-файле необходимо экранировать символы `[`, `]`, `'` и `\` из-за способа передачи полезной нагрузки (payload).
- Пример: `\'You think this hurts? Just wait.\'`
