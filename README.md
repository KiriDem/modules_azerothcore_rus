# Модули для AzerpthCore

Здесь собранны модули для AzerpthCore в той или иной степени переведенные на русский язык.<br>

## 💬 Все модули работают на моем домашнем сервере.
В основном во всех модах переведены внутри игровые сообщения, скрипты sql и файлы настроек.
