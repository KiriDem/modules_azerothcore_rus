# Autosort модуль для Azerothcore

## Обзор

Реализует функцию «Упорядочить сумки» из актуальной версии World of Warcraft. Предметы в сумках будут автоматически отсортированы, а предметы, допускающие объединение в стопки, — сгруппированы так, чтобы занимать как можно меньше ячеек.

## Как установить

1. Клонируйте этот репозиторий в папку `modules` вашего репозитория AzerothCore. В результате там должна появиться папка `mod-autosort`.
2. Запустите CMake повторно, чтобы сгенерировать решение (solution).
3. Пересоберите проект.
4. После сборки файл `mod_autosort.conf.dist` появится в директории `configs/modules`; скопируйте его в папку с исполняемыми файлами сервера.
5. Запустите сервер; для этого модуля не требуется выполнение скриптов базы данных.

## Использование в игре

Этот модуль предоставляет три команды, доступные каждому игроку:
1. **.sort bags** — сортировка и объединение содержимого сумок игрока. Для специальных сумок (например, для трав, изделий из кожи и т. д.) предусмотрена отдельная группа сортировки: предметы из них не будут перемещаться в обычные сумки (как и ожидается).
2. **.sort bank** — сортировка и объединение содержимого банка игрока и сумок, находящихся в банке.
3. **.sort all** — сортировка всего содержимого (сумки + банк).
