# <img width="100" height="100" alt="icon" src="https://github.com/user-attachments/assets/093a515e-ac44-4e0a-812d-2e3d1847c71f" /> mod-dungeon-master

Процедурная система испытаний в подземельях для **AzerothCore** (WotLK 3.3.5a).

Игроки разговаривают с NPC-мастером подземелий, выбирают сложность, тему создания и подземелье — затем телепортируются в очищенный инстанс, вновь населенный тематическими врагами в масштабе уровня и боссом. Убивайте все подряд, чтобы заработать награды. Режим, подобный Roguelike, объединяет подземелья в цепочку с возрастающей сложностью, добавками и повышением характеристик до тех пор, пока группа не сотрется в порошок.

> ⚠️ **Ранняя разработка** — ожидайте ошибок и шероховатостей. Сообщения об ошибках приветствуются через раздел "Проблемы".

## Характеристики

### Основная система
- **37 подземелий** — Инстансы Classic, TBC и WotLK для 5 человек
- **9 тем существ** — Охота на Зверя, Логово Дракона, Вторжение Демонов, Стихийный Хаос, Твердыня Великана, Восстание Нежити, Оплот Гуманоидов, Механический Хаос, Случайный Хаос
- **6 уровней сложности** — от новичка до Гроссмейстера с настроенными множителями HP/урона/награды
- **Масштабирование уровня** — Масштабируйте существ до уровня вашей группы или используйте естественный диапазон уровней.
- **Любое подземелье, любой уровень** — Игрок 80-го уровня может запускать мертвые мины в масштабе 80 или с первоначальной сложностью
- **Настоящие боссы подземелий** — Финальные боссы выбираются из глобального пула всех боссов подземелий в инстансах Classic, TBC и WotLK в соответствии с тематикой сеанса.
- **Поддержка Групп** — Соло или группами до 5 человек
- **Поддержка групповой добычи** — Предметы, сброшенные врагами, поддерживают игровую механику групповой добычи, в которой участники группы бросают «Необходимость» или «Жадность» на соответствующие предметы.
- **Сложность для каждого игрока** — Количество HP и урона зависит от размера группы. Для одиночных игроков это количество уменьшается.
- **Автоматическое воскрешение** — Мертвые игроки оживают при входе, когда бой заканчивается.
- **Environmental damage scaling** — Опасности в местных подземельях уменьшены для групп с несоответствующим уровнем, их максимальное количество ограничено 3% HP за тик.
- **Система кулдаунов** — Настраиваемое время кулдауна для каждого персонажа между запусками
- **Постоянная статистика** — Отслеживает забеги, убийства, смерти, самое быстрое время прохождения каждого персонажа.
- **Статистика и таблицы лидеров** — Отдельное отслеживание для обычных запусков и в режиме roguelike. Обычная статистика отслеживает количество побед, убийств, смертельных исходов, соотношение K/D и самый быстрый клир. Статистика Roguelike отслеживает самый высокий уровень, большинство этажей, общее количество пройденных этажей и самый длительный пробег. Таблицы лидеров включают обычные самые быстрые прохождения, Roguelike наивысшего уровня и Roguelike большинства этажей — с выделением ваших собственных записей
- **Команды GM** — `.dm reload`, `.dm status`, `.dm list`, `.dm end`, `.dm clearcooldown`

### Режим Рогалика
- **Бесконечная прогрессия** — Очистите подземелье, телепортируйтесь в следующее, повторяйте до тех пор, пока не умрете
- **Возрастающая сложность** — Количество единиц здоровья противника и шкала урона для каждого уровня (линейная, затем экспоненциальная)
- **Накопление Бафов** — +10% ко всем характеристикам за очищенное подземелье (аура Благословения королей, повторно применяется при смерти)
- **Аффиксы в стиле Mythic+** — Укрепленный, Тиранический, Неистовый, Укрепляющий, Дикий; наслоен на настраиваемые пороговые значения уровня
- **Случайная ротация подземелий** — На каждом этаже выбирается новое подземелье, соответствующее вашему уровню.
- **Награды в масштабе уровней** — Лучшая добыча на более высоких уровнях с увеличивающимся шансом выпадения эпических предметов
- **NPC-Торговец** — Продавайте предметы, ремонтируйте снаряжение и покупайте боеприпасы/реагенты в начале каждого этажа.

## Установка

1. **Клонирование в модули:**
   ```bash
   cd azerothcore-wotlk/modules
   git clone https://github.com/your-username/mod-dungeon-master.git
   ```

2. **Повторно запустите CMake и перекомпилируйте** сервер.

3. **Запустит скрипт SQL в базе данных acore_world:**
   ```sql
   SOURCE data/sql/db-world/base/dm_setup.sql
   ```

4. **Запустит скрипт SQL в базе данных acore_characters:**
   ```sql
   SOURCE data/sql/db-characters/base/dm_characters_setup.sql
   ```

5. **Скопируйте .conf файл:**
   ```bash
   cp modules/mod-dungeon-master/conf/mod_dungeon_master.conf.dist etc/mod_dungeon_master.conf
   ```

6. **Перезапустите сервер.** NPC "Мастер подземелий" появляется автоматически во всех крупных городах.

## Как Это Работает

### Стандартный режим

1. Поговорите с NPC Мастером Подземелий
2. Выберите **уровень сложности** (Новичок → Гроссмейстер)
3. Выберите **режим масштабирования**:
   - **Маштаб Группы** — существа соответствуют среднему уровню вашей группы
   - **Используйте сложность подземелья** — существа остаются в естественном диапазоне уровней уровня.
4. Выберите **Тему существ** (Нежить, Демоны, Звери и т.д.)
5. Выберите **Подземелье**
6. Подтвердить → телепортироваться внутрь → убить всех → собрать награды → телепортироваться наружу

### Режим Рогалика

1. Поговорите с NPC → выберите **Забег в стиле Рогалика**
2. Выберите сложность, масштабирование и тему (или случайную тему для каждого этажа).
3. Очистить этаж 1 → получить + 10% усиления ко всей статистике → автоматический переход на этаж 2
4. Враги становятся сильнее с каждым уровнем; аффиксы вступают в силу на уровне 3+
5. Продолжайте, пока не умрете — достигнутый наивысший уровень, очищенные этажи и убийства сохраняются в таблице лидеров рогалика (отдельно от обычных забегов).

### Масштабирование уровня

Существа принудительно масштабируются до целевого уровня сеанса независимо от их исходного шаблона. Гуль Ледяной Короны 80-го уровня становится мобом 14-го уровня с соответствующими HP, уроном, броней и табличкой с именем.

- **Эффективный уровень** = средний уровень группы (маштабирование для группы) или средняя точка уровня (используется сложность подземелья).
- **Диапазон уровней** = EffectiveLevel ± `LevelBand` (по умолчанию ±3), привязанный к диапазону уровня.
- Статистика пересчитывается из `creature_classlevelstats` для целевого уровня.

## Настройка

Все настройки доступны в `mod_dungeon_master.conf`. Ключевые параметры:

### Scaling

| Параметр | По умолчанию | Описание |
|---------|---------|-------------|
| `Scaling.LevelBand` | 3 | Окно уровня существа: ± N уровней от группы |
| `Scaling.SoloMultiplier` | 0.5 | HP/Снижение урона для одиночных игроковs |
| `Scaling.PerPlayerHealth` | 0.25 | Добавлено HP за каждого дополнительного участника (25%) |
| `Scaling.BossHealthMult` | 8.0 | Множитель HP босса (в дополнение к масштабированию группы) |
| `Scaling.BossDamageMult` | 1.5 | Множитель урона от босса (только в масштабе группы, не суммируется с уровнем) |
| `Scaling.EliteHealthMult` | 2.0 | Множитель HP элитного мусора |

### Dungeon

| Параметр | По умолчанию | Описание |
|---------|---------|-------------|
| `Dungeon.BossCount` | 1 | Количество боссов за один проход |
| `Dungeon.EliteChance` | 20 | % шанс, что мусорная толпа появится как элитная |
| `Dungeon.AggroRadius` | 15.0 | Дальность обнаружения в ярдах |
| `Dungeon.Whitelist` | (empty) | Разрешаемые ID карт, разделенные запятыми (пусто = все) |
| `Dungeon.Blacklist` | (empty) | ID карт, разделенные запятыми, для исключения |

### Roguelike

| Параметр | По умолчанию | Описание |
|---------|---------|-------------|
| `Roguelike.Enable` | 1 | Главный переключатель для режима Рогалик |
| `Roguelike.TransitionDelay` | 30 | Секунды между этажами |
| `Roguelike.HpScalingPerTier` | 0.10 | +10% здоровья противника за уровень |
| `Roguelike.DmgScalingPerTier` | 0.08 | +8% урона противнику за уровень |
| `Roguelike.ExponentialThreshold` | 5 | Уровень, на котором масштабирование идет экспоненциально |
| `Roguelike.ExponentialFactor` | 1.15 | Экспоненциальный фактор роста |
| `Roguelike.AffixStartTier` | 3 | Первый уровень с аффиксами |
| `Roguelike.SecondAffixTier` | 7 | Второй одновременный аффикс |
| `Roguelike.ThirdAffixTier` | 10 | Третий одновременный аффикс |

### Rewards

| Параметр | По умолчанию | Описание |
|---------|---------|-------------|
| `Rewards.BaseGold` | 50000 | Золото за завершение (мед) |
| `Rewards.XPMultiplier` | 1.0 | Множитель опыта убийства |
| `Rewards.ItemChance` | 80 | % шанс получения награды за предмет по завершении |
| `Rewards.RareChance` | 40 | % шанс получения предмета редкого качества |
| `Rewards.EpicChance` | 15 | % шанс получения предмета эпического качества |

Смотрите `mod_dungeon_master.conf.dist` с полным списком описаний.

| Аффикс | Эффект |

## Технические примечания

- **Совместимость с AzerothCore** — Создан на основе официального репозитория [AzerothCore](https://github.com/azerothcore/azerothcore-wotlk). Никаких основных модификаций не требуется.
- **Потокобезопасность** — Карты сеансов и время восстановления защищены мьютексами для обеспечения безопасности нескольких игроков.
- **Асинхронная обработка телепортации** — 30-секундный льготный период после телепортации для предотвращения ложного "оставленного" обнаружения.
- **Нейтрализация InstanceScript** — Все столкновения с боссами помечаются как ВЫПОЛНЕННЫЕ, чтобы предотвратить вмешательство собственных скриптов.
- **Очистка дебаффа** — Сохраняющиеся дебаффы с убитых существ снимаются перед каждым этажом.
- **Пользовательский AI существ** —  Мусорные существа используют `DungeonMasterCreatureAI` который патрулирует радиус 5 ярдов вокруг точек возрождения, активно сканирует игроков в радиусе действия агрессии (с резервным таймером на 1 секунду для случаев с краями сетки) и зацепляет `JustDied` для правильного выбора времени добычи. Боссы сохраняют свой собственный искусственный интеллект со всеми оригинальными заклинаниями и боевой механикой без изменений.
- **Масштабирование урона от заклинаний босса** — Способности босса имеют жестко запрограммированные значения урона, рассчитанные для их первоначального диапазона уровней. Скрипт юнита перехватывает весь поступающий урон от сессионных боссов (заклинания, периодические атаки и ближний бой) и масштабирует его, используя `creature_classlevelstats` базовое соотношение урона между шаблонным уровнем босса и эффективным уровнем сеанса. Это гарантирует, что заклинание босса 70-го уровня наносит пропорционально правильный урон отряду 25-го уровня.
- **Многофазное обнаружение босса** — Когда босс умирает, система ждет 5 секунд и сканирует новых элитных существ / боссов вблизи места смерти. При обнаружении существа 2-й фазы оно автоматически повышается до статуса босса, и первоначальная смерть не засчитывается как убийство.
- **Поддержка групповой добычи** — Добыча существ запускает систему бросков Потребности/Жадности группы для предметов, качество которых превышает пороговое значение для группы.
- **Масштабирование урона от босса** — Урон от босса зависит только от размера группы (не суммируется с умножителем урона уровня сложности), чтобы предотвратить чрезмерный урон в сочетании с масштабированием уровня.
- **Стандарты AzerothCore** — Все запросы используют стандартные имена AzerothCore. Никаких специфических зависимостей.

## Структура файлов

```
mod-dungeon-master/
├── CMakeLists.txt
├── conf/
│   └── mod_dungeon_master.conf.dist
├── data/sql/

    ├── RoguelikeTypes.h            # Структуры данных для roguelike
    ├── DungeonMaster_loader.cpp    # Точка входа модуля
    └── scripts/
        ├── npc_dungeon_master.cpp  # Меню сплетен NPC

        ├── dm_command_script.cpp   # Комманды GM

        └── dm_world_script.cpp     # Хуки жизненного цикла сервера
```
