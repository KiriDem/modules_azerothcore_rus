# mod-dress-npc

Порт модуля [Rochet2's Dress-NPCs](https://rochet2.github.io/Dress-NPCs.html) для AzerothCore.

Надевайте на NPC доспехи и выбирайте их расу, пол и черты лица 
— всё это делается исключительно через базу данных, без внесения изменений в клиент.

## Как это работает

Персонаж в экипировке получает базовую модель отображения, соответствующую выбранной расе и полу, 
а также флаг `UNIT_FLAG2_MIRROR_IMAGE`. Затем клиент запрашивает у сервера данные для «зеркальной копии» (mirror image)
 и модуль передает информацию об облачении (цвет кожи, лицо, прическа, гербовая накидка гильдии и 11 слотов отображения предметов), 
 в результате чего клиент отрисовывает NPC как полноценно экипированного игрового персонажа.

## Установка

1. Скопируйте этот модуль в директорию `modules/` исходного кода AzerothCore.
2. Запустите CMake повторно и выполните сборку.
3. SQL-скрипты из папки `data/sql/db-world/` автоматически применяются к базе данных `world` 
с помощью встроенного в сервер механизма обновления БД (параметр `Updates.EnableDatabases` должен включать БД `world`, что установлено по умолчанию).
4. (Опционально) скопируйте файл `conf/mod_dress_npc.conf.dist` в ту же папку, где находится `worldserver.conf`, и настройте его.

## Использование

1. Создайте комплект снаряжения в таблице `creature_template_outfits`. Поле `entry` — это произвольный ID на ваш выбор. 
- Столбцы слотов предметов (`head`, `shoulders`, ... `tabard`): **положительные** значения соответствуют ID предметов (например, `19019` для «Громовой Ярости»), **отрицательные** — ID отображения предметов (displayid, например, `-30606`). 
- `guildid` указывает на существующую гильдию в вашем игровом мире; если надет гербовый накидка (tabard), существо будет отображать эмблему этой гильдии. 
- `npcsoundsid` ссылается на файл `NPCSounds.dbc` и определяет звук приветствия, используемый серверной системой воспроизведения звуков (см. настройки конфигурации). 
- Некоторые варианты внешнего вида (скины) ограничены клиентом по классу (например, для скинов или глаз рыцаря смерти требуется `class` = 6). 
Можно использовать и неигровые расы (наги и т. д.) — экспериментируйте.
2. Назначьте комплект NPC:
- `creature_template_outfits_npcs` (`creature_entry`, `outfit_entry`) — одевает **каждый экземпляр (спавн)** существа данного шаблона. 
- `creature_template_outfits_spawns` (`spawn_guid`, `outfit_entry`) — одевает **один конкретный экземпляр** и переопределяет назначение, заданное для шаблона в целом.
3. Перезапустите сервер или используйте команду `.dressnpc reload` (она также обновляет/восстанавливает внешний вид существ, уже находящихся в игровом мире).

### Пример

Нарядите NPC с ID 6 (при каждом появлении) как ночную эльфийку, используя экипировку, заданную через displayID:

```sql
INSERT INTO `creature_template_outfits`
    (`entry`, `race`, `gender`, `skin`, `face`, `hair`, `haircolor`, `facialhair`,
     `head`, `shoulders`, `body`, `chest`, `waist`, `legs`, `feet`, `wrists`, `hands`, `back`, `tabard`)
VALUES
    (1, 11, 1, 14, 4, 10, 3, 5, -31286, -43617, 0, -26267, -26270, -26272, 0, 0, -43698, 0, 0);

INSERT INTO `creature_template_outfits_npcs` (`creature_entry`, `outfit_entry`) VALUES (6, 1);
```

### Использование в C++

```cpp
#include "DressNpcMgr.h"

// одеться в комплект, загруженный из базы данных
if (std::shared_ptr<CreatureOutfit> const& outfit = sDressNpcMgr->GetOutfitFor(creature))
    sDressNpcMgr->ApplyOutfit(creature, outfit);
```


## Отличия от оригинального патча

В оригинальной реализации наряды можно использовать в качестве **фиктивных displayid** (значений, превышающих 2147483647) везде, где ожидается `modelid` (`creature_template.modelidX`, `creature.modelid`, морфы SmartAI, `game_event_model_equip`, `SetDisplayId(...)`). Это требует внесения изменений в механизм разрешения моделей в ядре и не может быть реализовано через модуль. Поэтому используется иной подход:

- Назначение комплектов внешнего вида (outfits) осуществляется с помощью двух приведенных выше таблиц соответствия (на основе записи существа или GUID точки появления).
- Смена облика существа на комплект внешнего вида через SmartAI или `game_event_model_equip` **не** поддерживается.
- В коде C++ используйте `sDressNpcMgr->ApplyOutfit(creature, outfit)` вместо метода `creature->SetOutfit(...)`, предусмотренного патчем.
- Если скрипт или заклинание меняют облик уже «одетого» существа на другую модель, комплект внешнего вида перестает отображаться до тех пор, пока существо не вернется к своей базовой модели (например, после возрождения); это соответствует стандартному поведению игры, при котором смена модели приводит к снятию комплекта.

## Известные проблемы (унаследованные от оригинала, на стороне клиента)

- Портреты NPC иногда могут отображаться некорректно.
- Невозможно отобразить облики, недоступные игрокам для данной расы.
- NPC не воспроизводят приветственную реплику без использования специального серверного решения или клиентского патча.
