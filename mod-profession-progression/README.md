# mod-profession-progression

> [!WARNING]
> При входе в игру в чате появляется сообщение:<br>
> Profession Progression: %u/%u основных профессий. Свободные слоты для профессий: %u. Эра: %s, кап: %u.<br>
> и<br>Profession Progression: Уровень этой профессии в данный момент ограничен значением %u. Чтобы продолжить развитие, повысьте уровень связанной профессии или откройте следующую Эру профессий.<br>
> <br>
> К сожалению автор мода пока не поправил в коде эти досадные ошибки.


Система прогрессивного открытия слотов для основных профессий в AzerothCore с учетом ограничений уровней мастерства, характерных для версий Vanilla, TBC и Wrath.

## Правила

- Вы начинаете с 2 слотами для основных профессий.
- Если уровень мастерства обеих ваших основных профессий достигает 75, открывается 3-й слот.
- Если уровень мастерства обеих основных профессий достигает 150, открывается 4-й слот.
- Уровень дополнительных профессий не может превышать более низкий показатель мастерства из пары профессий, открытых ранее.
- Когда 3-я и 4-я профессии достигают максимального уровня мастерства для текущей эпохи, открываются 5-й и 6-й слоты.
- Когда 5-я и 6-я профессии достигают максимума для текущей эпохи, открываются 7-й и 8-й слоты, и так далее.

Модуль управляет только дополнительными слотами для основных профессий и лимитами мастерства; он не отменяет стандартные требования к обучению у тренеров профессий.

## Расчет для эры

Режим Vanilla:

```ini
ProfessionProgression.ExpansionStage = 0
ProfessionProgression.VanillaSkillCap = 300
```

Активные основные профессии: 9

- Алхимия
- Кузнечное дело
- Зачарование
- Инженерное дело
- Травничество
- Кожевничество
- Горное дело
- Снятие шкур
- Портняжное дело

Режим TBC:

```ini
ProfessionProgression.ExpansionStage = 1
ProfessionProgression.TbcSkillCap = 375
```

Активные основные профессии: 10, добавляется ювелирное дело.

Режим Wrath:

```ini
ProfessionProgression.ExpansionStage = 2
ProfessionProgression.WrathSkillCap = 425
```

Активные основные профессии: 11 (добавлено Начертание).

## Установка

Скопируйте папку в:

```text
Z:\ac\modules\mod-profession-progression
```

Копировать/редактировать конфигурацию:

```text
Z:\ac\modules\mod-profession-progression\conf\mod-profession-progression.conf.dist
```

Затем пересоберите AzerothCore.

## Примечания

В этот ZIP-архив намеренно не включен файл `CMakeLists.txt`.
